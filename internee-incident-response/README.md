# Incident Response Plan & Ransomware Simulation Lab

A Python incident response and ransomware simulation lab built on Kali Linux for an Internee.pk cybersecurity internship task.

## Modules & Artifacts
- `ransomware_ir_engine.py`: Simulates ransomware stages mapped to MITRE ATT&CK (`T1059.001`, `T1490`, `T1486`), executes containment/mitigation, and restores clean files with SHA-256 verification.
- `ir_staff_training.py`: Generates `STAFF_EMERGENCY_PLAYBOOK.md` and logs staff emergency response drill completion.
- `ir_report.py`: Compiles incident response and training metrics into `submission_summary.txt`.
- `index.html`: Interactive incident response console for GitHub Pages live deployment.
